# AutoIt Game Trainers

A collection of external game trainers written in **AutoIt**.

## About

This repository contains small game trainers developed with AutoIt, mainly for classic offline, single-player games.

The project is intended for educational purposes and aims to share knowledge about AutoIt scripting, Windows process interaction, and memory manipulation with the community.

## Dependencies

The following AutoIt UDFs are used across the projects:

- **NomadMemory UDF**
- **MetroGUI UDF**

Make sure the required dependencies are installed and configured in your AutoIt environment before compiling.
